# Better Dark Mode 0.1.0h — Full Package Fix

Better Dark Mode 0.1.0h is a packaging-only corrective release.

The published GitHub asset for 0.1.0g was discovered to be incomplete even though the 0.1.0g source tag itself was complete. Version 0.1.0h republishes the same tested 0.1.0g runtime behavior as a complete SMF install/upgrade package.

## What changed

- Rebuilt the release ZIP with every required package file.
- Includes the full PHP runtime, CSS, JavaScript, language file, admin icons, installer, and uninstaller.
- Added direct upgrade support from 0.1.0g.
- No functional or styling changes from the working 0.1.0g code.

## Compatibility

- SMF 2.1.x
- Curve2 / Curve-derived themes
- PHP 8.x friendly
- No SMF core-file edits

## 0.1.0g behavior retained

- System / Light / Dark modes
- Visitor sun/moon toggle
- Remembered visitor preference
- Dark Administration Center styling
- Better Gallery compatibility
- Topic/reply shell spacing and rounded-card polish
- Improved errors, dropdowns, quick-action buttons, and menu contrast

**Keep SMF familiar. Make it darker. Make it better.**
